# 华东理工大学学生会面试工作平台 - 使用说明

> 本文档面向所有使用者，涵盖项目概述、启动方式、各角色操作流程、访问地址及常见问题。

---

## 一、项目概述

### 1.1 系统简介

**华东理工大学学生会面试工作平台**是一个面向高校学生会招新场景的在线面试评分系统。支持多部门、多面试官协同工作，覆盖从候选人填报志愿到面试官评分的全流程。

### 1.2 核心功能

| 功能模块 | 说明 |
|---------|------|
| 📝 **候选人管理** | 候选人注册、填报志愿（最多3个）、查看排队状态 |
| 🎤 **面试官评分** | 7维度百分制评分、实时保存、多面试官协作 |
| 📢 **叫号看板** | 6部门轮播展示、实时排队状态、叫号/完成控制 |
| 👥 **用户管理** | 超级管理员管理所有账号和权限 |
| 📊 **数据导出** | 支持按部门、按候选人筛选导出评分数据 |

### 1.3 角色与权限

| 角色 | 账号标识 | 核心权限 |
|------|---------|---------|
| **候选人** | `candidate` | 注册、填报志愿、查看排队状态 |
| **面试官** | `interviewer` | 查看本部门场次、进行评分 |
| **部门管理员** | `subadmin` | 管理本部门数据、查看本部门评分 |
| **超级管理员** | `super_admin` | 全部权限：用户管理、评分管理、数据导出 |

### 1.4 部门代码

| 代码 | 部门名称 |
|------|---------|
| BGS | 办公室 |
| XCB | 宣传部 |
| QYB | 权益部 |
| XSB | 学术部 |
| WYB | 文艺部 |
| TYB | 体育部 |

### 1.5 评分维度（百分制，总分100分）

| 维度 | 分值 | 说明 |
|------|------|------|
| 表达能力 | 20分 | 语言表达、逻辑清晰度 |
| 简历得分 | 15分 | 简历完整度、经历相关性 |
| 创新能力 | 20分 | 创新思维、独特见解 |
| 责任心 | 15分 | 责任感、主动担当 |
| 逻辑思维 | 15分 | 分析问题、解决问题能力 |
| 团队协作 | 10分 | 沟通协作、团队意识 |
| 部门匹配度 | 5分 | 与部门需求的匹配程度 |

## 二、快速启动

### 2.1 系统要求

- **操作系统**：Windows 10 / 11
- **浏览器**：Chrome / Edge / Safari（推荐最新版）
- **Python**：3.10 或更高版本（**仅首次使用需安装**）
- **网络**：同一局域网内设备互通

### 2.2 首次使用（一次性设置）

#### 步骤 1：安装 Python

1. 访问 [Python 官网](https://www.python.org/downloads/) 下载 Python 3.10+
2. 运行安装程序，**务必勾选 "Add Python to PATH"**
3. 点击 "Install Now" 完成安装

#### 步骤 2：创建虚拟环境并安装依赖

在项目根目录 `网站设计\` 下打开终端（按住 Shift + 右键 → 在终端中打开），执行：

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

> 首次安装可能需要几分钟，请耐心等待

#### 步骤 3：初始化数据库

```bash
python manage.py migrate --run-syncdb
```

#### 步骤 4：创建超级管理员账号

```bash
python manage.py createsuperuser
```
按提示输入用户名、邮箱、密码（密码至少 8 位）

#### 步骤 5：启动服务器

双击 `迅速启动\启动网站.bat`

启动成功后会显示访问地址，浏览器会自动打开登录页面。

### 2.3 日常使用

1. **启动**：双击 `迅速启动\启动网站.bat`
2. **停止**：双击 `迅速启动\stop.bat`

> ⚠️ 服务器电脑需要保持开机，且屏幕上不要关闭 "ECUST-Server" 窗口

### 2.4 手机访问（同一 WiFi）

启动成功后，命令行窗口会显示：

```
  Local (this PC):
    http://127.0.0.1:8000/login/

  LAN (all devices on same WiFi):
    http://192.168.x.x:8000/login/
```

手机连接同一 WiFi，在浏览器中输入 **局域网地址** 即可访问。

> 💡 **提示**：首次手机访问时若出现"无法连接"，请以**管理员身份**运行 `迅速启动\启动网站.bat` 一次（右键→以管理员身份运行），防火墙规则将被永久添加。

### 2.5 叫号管理员登录

叫号看板控制台使用独立密码登录：

- **访问地址**：`http://127.0.0.1:8000/board/admin/`
- **预设密码**：`ecust2026`

## 三、各角色操作流程

### 3.1 候选人流程

#### 第一步：注册账号

1. 访问 `http://服务器地址:8000/login/`
2. 点击页面下方的 **"创建报名账号"**
3. 填写信息：
   - 用户名（用于登录，建议用学号）
   - 密码（至少 8 位）
   - 姓名
   - 性别
   - 政治面貌
   - 手机号
   - 学号（格式：2xxxxx）
   - 辅导员姓名
4. 点击 **"确认注册"**

#### 第二步：登录系统

1. 返回登录页
2. 输入刚才注册的用户名和密码
3. 点击 **"登录"**
4. 登录成功后自动跳转到个人中心 `/profile/`

#### 第三步：填报志愿

1. 进入个人中心后，点击左侧菜单 **"志愿填报"**
2. 选择意向部门（可多选）
3. 保存后加入排队

#### 第四步：查看状态

在"排队页面"实时查看：
- 当前排队状态（排队中 → 已叫号 → 面试中 → 已完成）
- 前方等待人数
- 预计等待时间
- 被叫号时将弹出通知

---

### 3.2 面试官流程

#### 第一步：管理员创建面试官账号

由超级管理员在"面试官管理"中创建面试官账号，需指定：
- 用户名、密码
- 关联部门（BGS/XCB/QYB/XSB/WYB/TYB）

#### 第二步：登录并查看场次

1. 使用管理员分配的账号登录
2. 系统自动跳转到面试官工作台 `/interviewer/panel/`
3. 查看本部门所有面试场次列表

#### 第三步：进行评分

1. 点击某个场次进入详情
2. 查看待评分候选人列表
3. 点击候选人姓名打开评分面板
4. 在 7 个维度上评分（支持选择预设分值或拖动滑块）
5. 实时查看总分
6. 点击"保存评分"

#### 第四步：开始/结束面试

1. 主考官操作：点击"开始面试"按钮，候选人状态变为"面试中"
2. 评分完成后，面试官可随时保存
3. 主考官操作：点击"结束面试"，候选人状态变为"已完成"

---

### 3.3 部门管理员流程

#### 第一步：超级管理员分配部门管理员

由超级管理员在"用户管理"中创建部门管理员账号，指定部门。

#### 第二步：登录并查看数据

登录后进入部门管理员控制台 `/subaddmin/console/`，可查看：
- 本部门所有面试场次
- 场次内候选人名单及状态
- 面试官评分情况
- 本部门候选人评分数据

#### 第三步：查看评分详情

1. 进入"评分信息"页面
2. 按场次/候选人筛选
3. 查看详细评分数据（7维度得分 + 总分）

---

### 3.4 超级管理员流程

#### 访问地址

`http://服务器地址:8000/addmin/console/`

#### 功能一：用户管理

1. 进入"用户管理"页面
2. 可执行操作：
   - 创建用户（指定角色：超级管理员/部门管理员/面试官）
   - 编辑用户信息
   - 重置用户密码
   - 删除用户

#### 功能二：面试官管理

1. 进入"面试官管理"页面
2. 查看所有面试官列表
3. 可执行操作：
   - 创建面试官（关联部门、填写详细信息）
   - 编辑面试官信息
   - 分配面试官到组

#### 功能三：面试场次管理

1. 进入"面试场次"页面
2. 查看所有面试场次
3. 可执行操作：
   - 创建场次（指定部门、面试官、候选人）
   - 修改场次状态
   - 查看场次详情

#### 功能四：查看评分信息

1. 进入"评价信息"页面
2. 按部门/候选人/场次筛选
3. 查看所有评分数据
4. 支持导出

#### 功能五：数据导出

1. 在各管理页面点击"导出"按钮
2. 选择导出范围
3. 下载 Excel 格式数据

### 3.5 叫号管理员流程（独立密码登录）

## 六、常见问题

### Q1：手机无法访问怎么办？

1. 确认手机和电脑连接**同一 WiFi**
2. 确认电脑已运行 `迅速启动\启动网站.bat`
3. 尝试以**管理员身份**运行启动脚本
4. 关闭电脑防火墙测试
5. 检查启动窗口显示的局域网地址是否正确

### Q2：忘记密码怎么办？

- **候选人**：在注册页重新注册新账号
- **面试官/部门管理员**：联系超级管理员重置密码
- **超级管理员**：运行 `python manage.py createsuperuser` 创建新账号

### Q3：页面显示"离线模式"怎么办？

这是正常现象。在 DEBUG 模式下（默认），系统使用内存模式处理实时通信，不影响核心功能。

### Q4：如何备份数据？

1. 关闭服务器（运行 `迅速启动\stop.bat`）
2. 复制 `db.sqlite3` 文件到安全位置
3. 恢复时将文件复制回原位置

### Q5：如何迁移到新电脑？

1. 将整个项目文件夹复制到新电脑
2. 在新电脑上安装 Python 3.10+
3. 按"首次使用"步骤操作
4. 复制 `db.sqlite3` 以保留原有数据

### Q6：叫号管理员密码如何修改？

在 `interview_system\settings.py` 中找到 `BOARD_ADMIN_PASSWORD` 修改：

```python
BOARD_ADMIN_PASSWORD = [
    '新密码',
]
```

### Q7：如何修改评分维度？

在 `interview\models.py` 中找到 `SCORE_DIMENSIONS` 列表修改：

```python
SCORE_DIMENSIONS = [
    {'code': 'expression', 'name': '表达能力', 'max_score': 20},
    # 添加/修改维度...
]
```

修改后重启服务器生效。

   - 监控系统运行状态
