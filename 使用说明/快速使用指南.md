### 关键理解

| 角色 | 需要安装？ | 操作 |
|------|-----------|------|
| 🖥️ **服务器电脑**（1台） | ✅ 需要安装 Python | 双击 `迅速启动\启动网站.bat`，一整天保持开机 |
| 📱 **手机用户**（所有面试官/候选人） | ❌ **不需要** | 打开手机浏览器，输入网址即可 |

## 📱 手机用户使用说明

### 第一步：连接 WiFi

确保手机与服务器电脑连接**同一个 WiFi**

### 第二步：打开浏览器

在手机上打开任意浏览器（推荐 Chrome 或 Safari）

### 第三步：输入网址

在服务器电脑屏幕上找到显示的网址，例如：

```
http://192.168.3.72:8000/login/
```

在手机浏览器地址栏输入此网址，回车访问

### 第四步：使用系统

- **候选人**：注册账号 → 登录 → 填报志愿 → 开始排队
- **面试官**：使用管理员分配的账号登录 → 查看面试场次 → 进行评分

> 💡 手机用户**全程无需安装任何 App 或软件**

## 🖥️ 服务器电脑设置

### 首次设置（仅一次）

#### 1. 安装 Python

1. 访问 https://www.python.org/downloads/
2. 下载 Python 3.10+ 版本
3. **重要**：安装时必须勾选 **"Add Python to PATH"**
4. 点击 "Install Now" 完成安装

#### 2. 创建虚拟环境并安装依赖

在项目根目录 `网站设计\` 下打开终端（按住 Shift + 右键 → 在终端中打开），执行：

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

> 首次安装可能需要几分钟，请耐心等待

#### 3. 初始化数据库

```bash
python manage.py migrate --run-syncdb
```

#### 4. 创建管理员账号

```bash
python manage.py createsuperuser
```
按提示输入用户名、邮箱、密码

#### 5. 启动服务器

双击 `迅速启动\启动网站.bat`

启动成功后会显示访问地址。

### 日常使用

1. **启动**：双击 `迅速启动\启动网站.bat`
2. **停止**：双击 `迅速启动\stop.bat`

> ⚠️ 服务器电脑需要保持开机，且屏幕上不要关闭 "ECUST-Server" 窗口

## ❓ 常见问题

### Q: 手机连不上怎么办？

1. 确认手机和电脑在**同一 WiFi**
2. 确认电脑已运行 `迅速启动\启动网站.bat`
3. 尝试以**管理员身份**运行启动脚本
4. 关闭电脑防火墙试试

### Q: 手机网址怎么找？

服务器启动后会显示：
```
  LAN (所有设备):
    http://192.168.3.72:8000/login/
```
手机浏览器输入这个完整地址

### Q: 忘记密码怎么办？

- 候选人：在注册页重新注册新账号
- 面试官/部门管理员：找超级管理员重置
- 超级管理员：运行 `python manage.py createsuperuser` 创建新账号

### Q: 换电脑怎么办？

1. 复制整个项目文件夹到新电脑
2. 在新电脑上安装 Python 3.10+
3. 按"首次设置"步骤操作
4. 复制 `db.sqlite3` 保留原有数据
