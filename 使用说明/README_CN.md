# 华东理工大学学生会面试工作平台

## 一、系统架构

```
+-------------------+         同一 WiFi         +-------------+
|  1 台电脑（服务器） |  <---------------------->  |  任何设备    |
|                   |                            | （手机/电脑）|
|  需要：Python     |                            |  需要：      |
|  双击 bat 启动    |                            |  浏览器      |
|  保持开机         |                            |  网址        |
+-------------------+                            +-------------+
```

**手机用户不需要安装任何东西。** 只需打开浏览器输入网址即可。

---

## 二、快速开始（首次使用）

### Step 1：安装 Python（仅服务器电脑需要）

1. 访问 https://www.python.org/downloads/
2. 下载 Python 3.10+ 版本
3. **重要**：安装时必须勾选 **"Add Python to PATH"**
4. 点击 "Install Now" 完成安装

### Step 2：创建虚拟环境并安装依赖

在项目根目录 `网站设计\` 下打开终端（按住 Shift + 右键 → 在终端中打开），执行：

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

> 首次安装可能需要几分钟，请耐心等待

### Step 3：初始化数据库

在终端中继续执行：

```bash
python manage.py migrate --run-syncdb
```

### Step 4：创建超级管理员账号

```bash
python manage.py createsuperuser
```
按提示输入用户名、邮箱、密码（密码至少 8 位）

### Step 5：启动服务器

双击 `迅速启动\启动网站.bat`

启动成功后会显示：
```
============================================
  Server started!
============================================

  Local (this PC):     http://127.0.0.1:8000/login/
  LAN (mobile):       http://192.168.3.72:8000/login/
  Board Display:      http://127.0.0.1:8000/board/
  Board Admin:        http://127.0.0.1:8000/board/admin/
  Board Admin PW:     ecust2026
```

浏览器会自动打开登录页面。

## 三、如何登录网站（重点）

### 3.1 访问登录页

**在电脑上**：浏览器自动打开，或手动访问 `http://127.0.0.1:8000/login/`

**在手机上**：
1. 手机连接与服务器电脑**同一 WiFi**
2. 打开浏览器（推荐 Chrome 或 Safari）
3. 输入服务器显示的局域网地址，例如：
   ```
   http://192.168.3.72:8000/login/
   ```
4. 按回车键访问

### 3.2 候选人（面试者）登录

**第一步：注册账号**
1. 打开登录页 `/login/`
2. 点击页面下方的 **"创建报名账号"**
3. 填写信息：
   - 用户名（用于登录，建议用学号）
   - 密码（至少 8 位）
   - 姓名
   - 性别
   - 政治面貌
   - 手机号
   - 学号（格式：2xxxxx）
   - 辅导员姓名
4. 点击 **"确认注册"**

**第二步：登录系统**
1. 返回登录页
2. 输入刚才注册的用户名和密码
3. 点击 **"登录"**
4. 登录成功后自动跳转到个人中心 `/profile/`

**第三步：填报志愿**
1. 进入个人中心后，点击左侧菜单 **"志愿填报"**
2. 选择意向部门（可多选）
3. 保存后加入排队

### 3.3 面试官登录

面试官账号由**超级管理员创建**，无法自行注册。

1. 获取管理员分配的用户名和密码
2. 打开登录页 `/login/`
3. 输入用户名和密码
4. 点击 **"登录"**
5. 登录成功后自动跳转到面试官工作台 `/interviewer/panel/`

### 3.4 超级管理员登录

使用 `createsuperuser` 创建的账号：
1. 打开登录页 `/login/`
2. 输入超级管理员的用户名和密码
3. 点击 **"登录"**
4. 登录成功后自动跳转到超级管理员控制台 `/addmin/console/`

### 3.5 部门管理员登录

部门管理员账号由超级管理员创建：
1. 打开登录页 `/login/`
2. 输入部门管理员的用户名和密码
3. 点击 **"登录"**
4. 登录成功后自动跳转到部门管理控制台 `/subaddmin/console/`

### 3.6 叫号管理员登录（独立入口）

叫号管理员使用**独立密码**登录，账号由系统预设：
1. 访问：`/board/admin/`（注意：这不是普通登录页）
2. 输入预设密码：`ecust2026`
3. 点击 **"登录"**
4. 登录成功后进入叫号管理控制台

### 3.7 忘记密码怎么办？

| 角色 | 解决方法 |
|------|---------|
| 候选人 | 在注册页重新注册新账号，或联系超级管理员重置 |
| 面试官 | 联系超级管理员重置密码 |
| 部门管理员 | 联系超级管理员重置密码 |
| 超级管理员 | 运行 `python manage.py createsuperuser` 创建新账号 |

## 六、日常使用流程

### 启动服务器
1. 双击 `迅速启动\启动网站.bat`
2. 等待浏览器自动打开
3. 保持此窗口开启（关闭则停止服务）

### 停止服务器
1. 双击 `迅速启动\stop.bat`
2. 或直接关闭 "ECUST-Server" 窗口

### 重启服务器
如果服务器异常：
1. 先运行 `迅速启动\stop.bat` 停止
2. 再运行 `迅速启动\启动网站.bat` 启动

## 八、常见问题

### Q1：手机连不上怎么办？

1. 确认手机和电脑在**同一 WiFi**
2. 确认电脑已运行 `迅速启动\启动网站.bat`
3. 尝试以**管理员身份**运行启动脚本
4. 关闭电脑防火墙试试
5. 在手机浏览器访问 `http://电脑IP:8000` 看是否能打开

### Q2：服务器启动后浏览器没打开？

1. 手动访问 `http://127.0.0.1:8000/login/`
2. 检查 "ECUST-Server" 窗口是否有错误信息

### Q3：登录提示"用户名或密码错误"？

1. 确认用户名和密码输入正确（注意大小写）
2. 候选人如果还没注册，请先点击"创建报名账号"
3. 面试官/管理员账号由超级管理员创建，不能自行注册

### Q4：忘记密码怎么办？

- 候选人：可重新注册新账号
- 其他角色：联系超级管理员在后台重置密码
- 超级管理员：运行 `python manage.py createsuperuser` 创建新账号

### Q5：数据库错误或启动失败？

1. 在项目目录打开终端
2. 运行 `python manage.py migrate` 初始化数据库
3. 如果还不行，删除 `db.sqlite3` 后重新初始化

### Q6：如何备份数据？

1. 关闭服务器（运行 `迅速启动\stop.bat`）
2. 复制 `db.sqlite3` 文件到安全位置
3. 恢复时将文件复制回原位置

### Q7：首次安装完整步骤？

```bash
# 1. 安装 Python 3.10+（勾选 Add to PATH）

# 2. 在项目根目录打开终端
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

# 3. 初始化数据库
python manage.py migrate --run-syncdb

# 4. 创建管理员账号
python manage.py createsuperuser

# 5. 启动服务器
#    双击 迅速启动\启动网站.bat
```
